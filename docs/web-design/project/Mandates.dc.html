How mandates behave One or two live, never more. They sit above the briefing and count toward "needs an answer" in the header. Answering is a choice. No modal, no gate. Letting one lapse is a decision, and the card says what followed. Blowback always links back to the action that caused it. Each seat sees its own framing. The same event may reach another seat as an opportunity. You never see theirs.
